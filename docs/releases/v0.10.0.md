# Skill Manager 0.10.0 Public Preview

This feature preview installs sources that ship one skill name from several
directories, installs a skill under another name when another source already
owns its name, and adds optional TypeSafe recommendations to the Skill Advisor
with your own API key. It supersedes `v0.9.0` for Apple Silicon Macs running
macOS 13 or newer.

## Downloads

- `skill-manager-desktop-0.10.0-macos-arm64.zip` — `Skill Manager.app` with the
  Dashboard, Skills, Skill Sets, Sources, and Advisor interfaces.
- `skill-manager-cli-0.10.0-macos-arm64.tar.gz` — the `skill-manager` CLI/TUI,
  advisor API, README, MIT license, and third-party notices.
- `SHA256SUMS.txt` — SHA-256 digests for both archives.

Download `SHA256SUMS.txt` with the artifacts and verify both archives from the
same directory:

```bash
shasum -a 256 -c SHA256SUMS.txt
```

## What Changed

- **Duplicate skill names inside one source.** A source that ships the same
  skill name from several directories no longer fails to install. Identical
  copies install from one canonical copy, and the output names it. Copies with
  differing content are never guessed: the CLI lists every copy as a pasteable
  `--skill <name>=<path>` form, and the desktop install matrix shows a copy
  picker.

  ```bash
  skill-manager install https://github.com/example/agent-skills --tool codex \
    --skill example-skill=plugin/skills/example-skill
  ```

- **Install a skill under another name.** When another installed source already
  owns a skill's name, the blocked install now suggests an install name you can
  paste with `--as`. In the desktop install dialog, the row asks for an install
  name prefilled with the suggestion and is never preselected.

  ```bash
  skill-manager install https://github.com/example/tools --tool claude \
    --as 'alpha=alpha-example'
  ```

  The second skill is an independent entry that you toggle, favorite, or add to
  a Skill Set by its install name. Reinstall, update, and `extend` keep it.
  `SKILL.md` is never edited, so Claude Code shows `/alpha-example` while Codex
  and Grok may list both installs under the same label.
- **Optional TypeSafe recommendations for the Skill Advisor.** Local ranked
  search remains the default and sends nothing off the machine. Selecting
  TypeSafe on the new desktop **Advisor** screen, or with
  `skill-manager advisor provider use typesafe`, together with your own
  TypeSafe API key from the macOS keychain or `TYPESAFE_API_KEY`, lets
  `skill-manager advisor recommend` send the task brief plus skill names and
  descriptions to TypeSafe for a model-ranked selection. A stored key alone
  never enables cloud use. See [PRIVACY.md](../../PRIVACY.md) for the data flow.
- Strict dry-runs no longer let `git status` rewrite a managed checkout's
  `.git/index`.

## Upgrade Note

`state.json` is now written as manifest version 3 to record install names.
Skill Manager `0.9.0` and earlier refuse a version 3 file. To go back to an
older release, restore a pre-upgrade copy of `state.json` from
`~/.skill-manager/backups/`.

## Desktop Installation

1. Expand `skill-manager-desktop-0.10.0-macos-arm64.zip`.
2. Move `Skill Manager.app` to `/Applications`.
3. Control-click the application, choose **Open**, and confirm **Open**.

The application is ad-hoc signed but not Developer ID signed or notarized. If
macOS does not offer **Open**, try a normal launch once, then use **System
Settings → Privacy & Security → Open Anyway** after verifying the checksum and
that this release came from the expected repository.

## CLI Installation

```bash
tar -xzf skill-manager-cli-0.10.0-macos-arm64.tar.gz
install -m 0755 \
  skill-manager-cli-0.10.0-macos-arm64/skill-manager \
  "$HOME/.local/bin/skill-manager"
skill-manager --version
```

The expected version output is `skill-manager 0.10.0`.

The Skill Advisor remains opt-in. After installing the CLI, install the
first-party skill from this repository:

```bash
skill-manager install https://github.com/dees91/agent-skill-manager \
  --tool both --skill skill-advisor
```

## Preview Limitations

- This is a public preview, not a stable release.
- Only Apple Silicon macOS 13 or newer is supported by these binaries.
- There is no Developer ID signature, notarization, universal binary, DMG,
  auto-update, telemetry, SBOM, or build provenance attestation.
- Skill Manager uses fixed provider paths under the current user's home
  directory. Custom Claude, Codex, Muse, or Grok skill roots, `GROK_HOME`,
  project-level skill directories, and provider plugin skills are out of scope.
- An install name is chosen once per source. To change it, uninstall the source
  and install it again with a different `--as`. Claude `settings.json` skill
  overrides are keyed by folder name and do not follow an install name.
- Codex and Grok read the `name` inside `SKILL.md`, so two installs of one skill
  may show the same label there. Muse behavior with install names is
  unverified.
- TypeSafe recommendations need network access and a user-owned key; failures
  fall back to local candidates. Ad-hoc-signed builds may prompt for keychain
  access after each update.
- New skills are never installed automatically, and there is no way to dismiss
  one you do not want. A skill stops being reported only after it is installed.
- Install as OFF applies to the whole selection; `--off` never turns an already
  installed skill OFF.
- Repair clears worktree changes only. A checkout with local commits, a detached
  HEAD, a changed origin, or managed link drift is diagnosed but not resolved.
- Muse and Grok have no provider diagnostic, so their context-budget figures
  are always filesystem estimates against an assumed context window.
- Experimental skills.sh Discover code is not exposed in this build.
- Already running Claude Code, Codex, Muse, or Grok sessions may need to be
  restarted after skill visibility changes.
- Third-party skills contain instructions that Skill Manager does not audit or
  sandbox. Review their source before installing them.
