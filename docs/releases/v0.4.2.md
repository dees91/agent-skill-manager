# Skill Manager 0.4.2 Public Preview

This maintenance preview supersedes `v0.4.1` for Apple Silicon Macs running
macOS 13 or newer. It refreshes the application toolchains and dependencies,
including the Go standard library used by both binaries, and fixes startup on
profiles that do not yet contain any Skill Manager-owned sources.

## Downloads

- `skill-manager-desktop-0.4.2-macos-arm64.zip` — `Skill Manager.app` with the
  Dashboard, Skills, and Sources interfaces.
- `skill-manager-cli-0.4.2-macos-arm64.tar.gz` — the `skill-manager` CLI/TUI,
  README, MIT license, and third-party notices.
- `SHA256SUMS.txt` — SHA-256 digests for both archives.

Download `SHA256SUMS.txt` with the artifacts and verify both archives from the
same directory:

```bash
shasum -a 256 -c SHA256SUMS.txt
```

## What Changed

- Raised both Go modules to Go 1.26.6 so the distributed CLI and desktop
  binaries contain the current standard-library security fixes.
- Upgraded Wails to 2.14, Bubble Tea to 1.3.10, and Lip Gloss to 1.1.0.
- Updated React, TypeScript, Vite, and the related frontend test/build stack;
  source builds now require Node.js 22.12 or newer and npm 10 or newer.
- Fixed the desktop Sources view on an empty profile by serializing an empty
  managed-source collection as `[]` instead of `null`.
- Regenerated the dependency notices embedded in both release archives.

## Desktop Installation

1. Expand `skill-manager-desktop-0.4.2-macos-arm64.zip`.
2. Move `Skill Manager.app` to `/Applications`.
3. Control-click the application, choose **Open**, and confirm **Open**.

The application is ad-hoc signed but not Developer ID signed or notarized. If
macOS does not offer **Open**, try a normal launch once, then use **System
Settings → Privacy & Security → Open Anyway** after verifying the checksum and
that this release came from the expected repository.

## CLI Installation

```bash
tar -xzf skill-manager-cli-0.4.2-macos-arm64.tar.gz
install -m 0755 \
  skill-manager-cli-0.4.2-macos-arm64/skill-manager \
  "$HOME/.local/bin/skill-manager"
skill-manager --version
```

The expected version output is `skill-manager 0.4.2`.

## Preview Limitations

- This is a public preview, not a stable release.
- Only Apple Silicon macOS 13 or newer is supported by these binaries.
- There is no Developer ID signature, notarization, universal binary, DMG,
  auto-update, telemetry, SBOM, or build provenance attestation.
- Experimental skills.sh Discover code is not exposed in this build.
- Already running Claude Code or Codex sessions may need to be restarted after
  skill visibility changes.
- Third-party skills contain instructions that Skill Manager does not audit or
  sandbox. Review their source before installing them.
