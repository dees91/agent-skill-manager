# Skill Manager 0.4.0 Preview

This preview is the first downloadable Skill Manager release. It provides the
desktop application and terminal interface for Apple Silicon Macs running
macOS 13 or newer.

## Downloads

- `skill-manager-desktop-0.4.0-macos-arm64.zip` — `Skill Manager.app` with the
  Dashboard, Skills, Sources, and Discover interfaces.
- `skill-manager-cli-0.4.0-macos-arm64.tar.gz` — the `skill-manager` CLI/TUI,
  README, and MIT license.
- `SHA256SUMS.txt` — SHA-256 digests for both archives.

Download `SHA256SUMS.txt` with the artifacts and verify both archives from the
same directory:

```bash
shasum -a 256 -c SHA256SUMS.txt
```

## Desktop Installation

1. Expand `skill-manager-desktop-0.4.0-macos-arm64.zip`.
2. Move `Skill Manager.app` to `/Applications`.
3. Control-click the application, choose **Open**, and confirm **Open**.

The application is ad-hoc signed but not Developer ID signed or notarized. If
macOS does not offer **Open**, try a normal launch once, then use **System
Settings → Privacy & Security → Open Anyway** after verifying the checksum and
that this release came from the expected repository.

## CLI Installation

```bash
tar -xzf skill-manager-cli-0.4.0-macos-arm64.tar.gz
install -m 0755 \
  skill-manager-cli-0.4.0-macos-arm64/skill-manager \
  "$HOME/.local/bin/skill-manager"
skill-manager --version
```

The expected version output is `skill-manager 0.4.0`.

## Included Functionality

- Inspect and reversibly toggle Claude Code and Codex user skills.
- Group skills by source and stage deterministic bulk changes.
- Install, update, and uninstall managed Git or linked local sources.
- Use the macOS Sources workflow and experimental skills.sh Discover catalog.
- Inspect approximate global skill-catalog context pressure for both tools.

## Preview Limitations

- Only Apple Silicon macOS 13 or newer is supported by these binaries.
- There is no Developer ID signature, notarization, universal binary, DMG,
  auto-update, or telemetry.
- Already running Claude Code or Codex sessions may need to be restarted after
  skill visibility changes.
- Third-party skills contain instructions that Skill Manager does not audit or
  sandbox. Review their source before installing them.
