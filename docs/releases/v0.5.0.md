# Skill Manager 0.5.0 Public Preview

This feature preview adds reusable task recipes, temporary task-specific skill
activation, and favorites for large local skill catalogs. It supersedes
`v0.4.2` for Apple Silicon Macs running macOS 13 or newer.

## Downloads

- `skill-manager-desktop-0.5.0-macos-arm64.zip` — `Skill Manager.app` with the
  Dashboard, Skills, Skill Sets, and Sources interfaces.
- `skill-manager-cli-0.5.0-macos-arm64.tar.gz` — the `skill-manager` CLI/TUI,
  advisor activation API, README, MIT license, and third-party notices.
- `SHA256SUMS.txt` — SHA-256 digests for both archives.

Download `SHA256SUMS.txt` with the artifacts and verify both archives from the
same directory:

```bash
shasum -a 256 -c SHA256SUMS.txt
```

## What Changed

- Added **Skill Sets** to the macOS app. Save reusable, tool-agnostic skill
  recipes, preview their impact for Claude, Codex, or both, and stage them
  through the existing Pending/Apply workflow.
- Added the optional first-party **Skill Advisor** and a path-free CLI
  inventory API. The advisor can activate the smallest relevant set of local
  inactive skills for one task and return an opaque receipt for explicit,
  drift-safe cleanup.
- Added **Favorites** to the macOS Skills workspace. Star managed skills, find
  them with the Favorites filter, and keep them ahead of other skills without
  changing their ON/OFF state.
- Preserved missing Skill Set members and favorite names so they reconnect when
  a skill with the same basename is installed again.
- Refreshed the public demo and dashboard imagery to reflect the current
  interface.

## Desktop Installation

1. Expand `skill-manager-desktop-0.5.0-macos-arm64.zip`.
2. Move `Skill Manager.app` to `/Applications`.
3. Control-click the application, choose **Open**, and confirm **Open**.

The application is ad-hoc signed but not Developer ID signed or notarized. If
macOS does not offer **Open**, try a normal launch once, then use **System
Settings → Privacy & Security → Open Anyway** after verifying the checksum and
that this release came from the expected repository.

## CLI Installation

```bash
tar -xzf skill-manager-cli-0.5.0-macos-arm64.tar.gz
install -m 0755 \
  skill-manager-cli-0.5.0-macos-arm64/skill-manager \
  "$HOME/.local/bin/skill-manager"
skill-manager --version
```

The expected version output is `skill-manager 0.5.0`.

The Skill Advisor remains opt-in. After installing the CLI, install the
first-party skill for either provider from this repository:

```bash
skill-manager install https://github.com/dees91/agent-skill-manager \
  --tool both --skill skill-advisor
```

## Preview Limitations

- This is a public preview, not a stable release.
- Only Apple Silicon macOS 13 or newer is supported by these binaries.
- There is no Developer ID signature, notarization, universal binary, DMG,
  auto-update, telemetry, SBOM, or build provenance attestation.
- Experimental skills.sh Discover code is not exposed in this build.
- Already running Claude Code or Codex sessions may need to be restarted after
  skill visibility changes.
- Third-party skills contain instructions that Skill Manager does not audit or
  sandbox. Review their source before installing them.
